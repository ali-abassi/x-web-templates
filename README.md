## Preview

With Node.js installed, run `npm run dev`, then open http://localhost:4173 for the gallery. No dependency installation or build is required. Alternatively, run `python3 -m http.server 8000 --directory dist`.

## Edit a template

Each `templates/<name>/dist/` contains editable HTML, CSS, JavaScript, and assets. Its README describes customization and demo behavior. The root `dist/` is the existing gallery with copies of the templates and packaged downloads; these copies and ZIPs do not automatically regenerate when you edit a template.
