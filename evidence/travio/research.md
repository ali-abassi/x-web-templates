# Implementation and hosting evidence

The supplied still is the visual authority. The existing Swift AI native-dialog implementation and collection build/check code supplied the local pattern. This is a small static composition without a new SDK or runtime package, so broad prior-art research was not necessary.

Native dialog top-layer/inert behavior was cross-checked against https://developer.mozilla.org/en-US/docs/Web/API/HTMLDialogElement/showModal (current page modified 2026-01-26), and text constraint validation against https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/input/text . The actual Chromium interactions verify the installed browser boundary. No TypeScript was authored; ESLint enforces complexity <=5.

Hosting is the existing personal-account Cloudflare Pages project x-web-templates. Wrangler 4.130.0 is the installed version recorded by this repository. Unversioned no-install npx looked for absent 4.131.0; no new version was installed. Default Wrangler OAuth belongs to a different account and returned error10000. No account/login settings were changed. Existing repository hosting-research.md documents the correct established route: connector-bound personal account obtains a short-lived Pages upload token; Wrangler 4.130.0 uploads the files and returns its manifest; connector API publishes that manifest. Current Pages OpenAPI upload-token, deployment-create schema, project name, production branch main, subdomain and current deployment were verified. Exa is not exposed as an active tool; current official API schema and installed Wrangler help are the authoritative fallback. Credentials are never written to this evidence.
