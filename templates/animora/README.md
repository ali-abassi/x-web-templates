# AnimoraAI

An interactive character hero inspired by [Tanzil Chowdhury’s reference](https://x.com/iamtanzil_/status/2098018663089533246).

Open `dist/index.html` directly, or serve the folder with any static server. All art, fonts, CSS, and JavaScript are local. There are no runtime dependencies.

- Move a pointer or tap the scene: the pupils follow within bounded eye sockets.
- Focus the character and use arrow keys; Home centers its gaze.
- Choose blue, pink, orange, or violet. The entire scene changes palette.
- Pause tracking or enable reduced motion to keep the eyes still.
- Get Started opens a local name/color preset editor and JSON download.

No camera, eye tracking, AI generation, account, payment, or network service runs in this template. Presets download locally; input remains in the page until reload. The reference’s country-use claim and latency claims are intentionally replaced with truthful copy. Navigation opens local explanatory panels; no unobserved product pages are invented.

The original character PNG was created with the native image-generation tool. It is a new illustration, not the reference’s exact character. CSS/SVG pupils, highlights, icons, text, and controls are editable. Color variants reuse the artwork through hue rotation. Eye positions in CSS correspond to this specific PNG; replacing it requires remeasuring the two eye regions. No source-site code was copied.

Nimbus Sans is included under the license and font exception in `licenses/`. Exact reference font and original animation mechanism are unknown. This is an attributed design reconstruction, not an affiliated product.
