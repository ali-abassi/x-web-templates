# Arto+

[Live preview](https://x-web-templates.pages.dev/arto/) · [Download ZIP](https://x-web-templates.pages.dev/downloads/arto.zip)

![Arto dashboard screenshot](https://x-web-templates.pages.dev/assets/arto.png)

A single dark finance dashboard reconstructed from [Andrew Gurio’s original design](https://x.com/andrewgurio/status/2097988488146870482/photo/1), using the screenshot supplied by Ali. Attribution is not affiliation. Original native ChatGPT mountain photography; every chart, number, label and control is editable HTML/SVG/CSS.

Open `dist/index.html` directly or serve its folder. No install, API key, backend, or runtime dependency. Local Nimbus Sans fonts and license included. Edit `data.js` for the sample ledger, `chart.js` for the separate illustrative trend series, `app.js` for local interactions and `style.css` for layout. `assets/mountains.png` is the original generated backdrop.

Period buttons filter dated sample transactions and recalculate income, outcome and net savings. Total Balance remains the all-ledger current balance (opening balance plus income minus outcome). The eye hides only Total Balance. Metric cards filter income/outcome or explain savings. Search matches descriptions/categories/types/dates; View all expands the ledger. Row controls open details. The chart selector and keyboard day slider inspect a separate illustrative trend series; it is not recalculated from ledger additions. Fixed +12.4%, +8.6% and +15.2% comparison labels are illustrative, not computed financial results.

Quick actions preview a transfer/request, add sample income, or save a sample budget. Nothing sends, charges, connects to a bank or persists beyond this page. Adding income updates sample totals and transactions, then disables duplicate submission until input changes. Budgets shows the saved target. Use fictional information. Profile, notifications, cards, settings and goal panels are labelled sample interactions. Reload restores the initial data. No real payment, authentication, bank sync, or support service is connected.

Responsive sidebar navigation, native dialogs, keyboard focus, validation, no-results feedback, disabled-script reading, reduced-motion behavior and missing-art fallback are included. The table deliberately scrolls horizontally on narrow screens; the page itself does not overflow. No source motion was asserted from the supplied still.

[Evidence and generation prompt](https://github.com/ali-abassi/x-web-templates/tree/main/evidence/arto). One native image call; billing unavailable. No financial/model API calls.
