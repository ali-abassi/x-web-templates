# BuzzKit landing-page template

Standalone reconstruction of [Christo’s original post](https://x.com/chroxify/status/2097477196130529296) and the linked [BuzzKit website](https://buzzkit.dev). This template is not affiliated with BuzzKit and is not its notification backend.

Open dist/index.html, or serve dist locally. Edit index.html for content, all four dashboard scenes and links; style.css for the visual system; app.js for the bounded preview carousel. No framework or API keys. Local Open Runde fonts are included with their OFL notice. No upstream application code is copied.

The four scene controls support click and Left/Right/Home/End keys. Choosing a scene pauses automatic rotation. Pause stops the card and scene presentation; reduced motion starts paused. Dashboard-internal controls are illustrative HTML, like an editable product screenshot. The scene selector, preference switches, FAQs, copy control and links work. No notifications are sent; preference state only lasts until reload.

Features, Docs, Pricing and source links distinguish local preview anchors from the real project. Replace branding, product claims, example code and external destinations before publishing your own version. The six feature cards follow the live page’s hierarchy; supporting copy is original template copy.
