# Chatsheet

A light automation hero reconstructed from [Marcel Kargul’s reference](https://x.com/marcelkargul/status/2098877780293271731). Open dist/index.html directly, or serve dist with any static server.

Edit index.html for copy, navigation and inline SVG geometry; style.css for layout, palette and motion. App icons, raised tiles, connector paths, hub and panel labels are editable SVG. No runtime dependencies, remote fonts, API keys, images or backend. The original video is a visual reference, not redistributed website artwork. System serif/sans fonts replace the unidentified source typefaces.

The CTAs open local, clearly labelled information below the hero. They do not book calls, accept applications or connect services. Replace discovery links with your own calendar when customizing. Details also work without JavaScript. Motion pauses manually, in hidden pages, or for reduced motion. Without scripts the artwork is static. Navigation/reading are recomposed on mobile.
