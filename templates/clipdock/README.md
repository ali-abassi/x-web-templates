# clipdock

[Live preview](https://x-web-templates.pages.dev/clipdock/) · [Download ZIP](https://x-web-templates.pages.dev/downloads/clipdock.zip)

![clipdock screenshot](https://x-web-templates.pages.dev/assets/clipdock.png)

Standalone motion template inspired by [Supaste / Navbar Gallery](https://www.supaste.com/?ref=navbar.gallery). Discovered through [the original post](https://x.com/thedzianis/status/2097600028416381178?s=20).

Open dist/index.html or serve this folder with any static server. Edit HTML content, CSS design tokens and app.js behavior. All fonts and art are local; no build step or runtime dependency.

Motion: Navigation reveal, app preview lift on scroll, animated tab content.
Interaction: Open mobile menu, select clipboard category, edit and copy a local item.
Boundary: local demonstration only; no backend, account, message delivery or checkout. Reference credit is not affiliation or a claim to original assets.
