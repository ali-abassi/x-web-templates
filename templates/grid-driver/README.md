# grid-driver

[Live preview](https://x-web-templates.pages.dev/grid-driver/) · [Download ZIP](https://x-web-templates.pages.dev/downloads/grid-driver.zip)

![grid-driver screenshot](https://x-web-templates.pages.dev/assets/grid-driver.png)

Standalone motion template inspired by [Kimi / GetLayers](https://www.getlayers.ai/layer/kimi). Discovered through [the original post](https://x.com/thedzianis/status/2097600028416381178?s=20).

Open dist/index.html or serve this folder with any static server. Edit HTML content, CSS design tokens and app.js behavior. All fonts and art are local; no build step or runtime dependency.

Motion: Helmet burns away on entry; pointer briefly restores helmet; circuit lap on scroll; sticky cards.
Interaction: Toggle helmet and replay circuit.
Boundary: local demonstration only; no backend, account, message delivery or checkout. Reference credit is not affiliation or a claim to original assets.
