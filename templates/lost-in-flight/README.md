# lost-in-flight

[Live preview](https://x-web-templates.pages.dev/lost-in-flight/) · [Download ZIP](https://x-web-templates.pages.dev/downloads/lost-in-flight.zip)

![lost-in-flight screenshot](https://x-web-templates.pages.dev/assets/lost-in-flight.png)

Standalone motion template inspired by [Gabriel Beaugonin / 404s](https://www.gabrielbeaugonin.com/404?via=404sdesign). Discovered through [the original post](https://x.com/thedzianis/status/2097600028416381178?s=20).

Open dist/index.html or serve this folder with any static server. Edit HTML content, CSS design tokens and app.js behavior. All fonts and art are local; no build step or runtime dependency.

Motion: Planes cross viewport on independent paths; pause and reduced motion.
Interaction: Pause flight and follow a real local home link.
Boundary: local demonstration only; no backend, account, message delivery or checkout. Reference credit is not affiliation or a claim to original assets.
