# NeuroLink

[Live preview](https://x-web-templates.pages.dev/neurolink/) · [Download ZIP](https://x-web-templates.pages.dev/downloads/neurolink.zip)

![NeuroLink screenshot](https://x-web-templates.pages.dev/assets/neurolink.png)

A memorial-page hero reconstructed from [AETHER’s original clip](https://x.com/aether_uiux/status/2097650553782510046?s=20). Original native ChatGPT artwork supplies the ivory/gold gateway and transparent cloud layer. CSS moves the clouds around fixed text and architecture; this is an independent reconstruction, not the source’s unknown rendering mechanism. Only the visible hero is reconstructed. Attribution is not affiliation.

Open `dist/index.html` or serve the folder with any static server. Plain HTML, CSS, JavaScript, local art and licensed Nimbus Sans fonts; no install, backend, API key or runtime dependency. Edit copy in index.html, layout in style.css, local draft behavior in app.js and cloud controls in motion.js.

Create Memorial opens a local form. Add a name, optional years, and a memory; preview, edit, and download a text tribute. Drafts stay on this page until reload. Nothing uploads, publishes, persists to browser storage, or creates an account. No photo upload, invitation, real memorial hosting, authentication, checkout or support service is connected. Example tribute copy is fictional. Replace those boundaries before operating a real service.

Pause clouds freezes motion. Reduced motion and hidden pages also pause; no-JS reading remains static with native inline information panels and disabled editor buttons. Missing art or a blocked download preserves usable copy and drafts. Responsive and keyboard behavior are supported.

[evidence/neurolink](https://github.com/ali-abassi/x-web-templates/tree/main/evidence/neurolink) retains exact source, prompts, generation provenance, analysis limitations, rendered comparisons and checks. Two native image calls; native billing unavailable. One direct Gemini3.7 static source analysis, estimated$0.00473; motion claims were independently checked against actual frames.
