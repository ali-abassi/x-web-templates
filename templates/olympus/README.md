# Olympus

[Live preview](https://x-web-templates.pages.dev/olympus/) · [Download ZIP](https://x-web-templates.pages.dev/downloads/olympus.zip)

![Olympus screenshot](https://x-web-templates.pages.dev/assets/olympus.png)

Marble artwork, orbit motion, local task assignment and model examples. A reference-led reconstruction of [the original design](https://x.com/jxdhaa/status/2097647071721607222), with independently authored code and original artwork generated through native ChatGPT image generation. The source post contains still images; the animation is a new, restrained interpretation, not an observed source animation. Credit is not affiliation.

Open `dist/index.html`, or serve this folder with any static server. Edit the HTML content, CSS and `app.js`. Assets and fonts are local; no install, backend, API key or build step is needed. Font licenses are included. Keyboard controls, pause, reduced motion and script-free reading are supported.

Local demo boundary: assignment toggles, model selection, workflow run/reset, and standards disclosures. No real agents, models, integrations, accounts or compliance certifications are connected.

Artwork: temple, Apollo, reaching hands, fictional team mosaic and marble laptop philosopher. Model marks and security medallions are editable code illustrations, not copied logos.

Generation prompts and provenance: [`evidence/olympus-wandor/image-generation.json`](https://github.com/ali-abassi/x-web-templates/blob/main/evidence/olympus-wandor/image-generation.json) in the source repository. Native-tool billing was not available. Desktop/mobile captures and the delivery receipt are retained with the same evidence folder.
