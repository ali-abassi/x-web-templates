# Pixel World

[Live preview](https://x-web-templates.pages.dev/pixel-world/) · [Download ZIP](https://x-web-templates.pages.dev/downloads/pixel-world.zip)

![pixel-world screenshot](https://x-web-templates.pages.dev/assets/pixel-world.png)

An editable reconstruction of [Varun’s original post](https://x.com/orseliyas/status/2097307376143773730) and [portfolio](https://varunlohade.com). Its reference projects and name identify the source; replace them with your own before reuse. No affiliation is claimed.

Open dist/index.html or serve dist locally. No framework, API keys or backend. Edit index.html for copy, project links and contact fields; style.css for geometry, crop and color; app.js for the local contact draft and motion controls. Local Open Runde font files include their OFL notice.

Three original ChatGPT-generated layers: landscape.png contains the valley, canopy and desk; clouds.png and robot.png have real transparency. The CSS artboard keeps all layers in the same coordinate system when the viewport crops. Pause stops cloud/robot movement; reduced motion is static. This approximates the source’s ambient motion, not its exact robot joint articulation.

Explore my work scrolls to the portfolio section. Say hello opens a keyboard-accessible native dialog; the form downloads a local text draft and never sends it to anyone. With JavaScript disabled, the landscape stays still and contact guidance remains visible below the page. No account, storage, telemetry or live message integration.
