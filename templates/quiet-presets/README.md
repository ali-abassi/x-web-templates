# quiet-presets

[Live preview](https://x-web-templates.pages.dev/quiet-presets/) · [Download ZIP](https://x-web-templates.pages.dev/downloads/quiet-presets.zip)

![quiet-presets screenshot](https://x-web-templates.pages.dev/assets/quiet-presets.png)

Standalone motion template inspired by [Norma / Unsection](https://nor.ma/?ref=unsection.com). Discovered through [the original post](https://x.com/thedzianis/status/2097600028416381178?s=20).

Open dist/index.html or serve this folder with any static server. Edit HTML content, CSS design tokens and app.js behavior. All fonts and art are local; no build step or runtime dependency.

Motion: Smooth snap carousel via arrows, touch swipe and focus.
Interaction: Browse four presets and select one with visible local feedback.
Boundary: local demonstration only; no backend, account, message delivery or checkout. Reference credit is not affiliation or a claim to original assets.
