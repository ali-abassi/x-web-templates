# reality-studio

[Live preview](https://x-web-templates.pages.dev/reality-studio/) · [Download ZIP](https://x-web-templates.pages.dev/downloads/reality-studio.zip)

![reality-studio screenshot](https://x-web-templates.pages.dev/assets/reality-studio.png)

Standalone motion template inspired by [Reality is / Footer Design](https://www.reality-is.com/). Discovered through [the original post](https://x.com/thedzianis/status/2097600028416381178?s=20).

Open dist/index.html or serve this folder with any static server. Edit HTML content, CSS design tokens and app.js behavior. All fonts and art are local; no build step or runtime dependency.

Motion: Drifting gradient and fading geometric pointer trails.
Interaction: Move pointer, pause motion, expand services and copy contact.
Boundary: local demonstration only; no backend, account, message delivery or checkout. Reference credit is not affiliation or a claim to original assets.
