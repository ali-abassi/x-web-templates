# Swift AI

[Live preview](https://x-web-templates.pages.dev/swift-ai/) · [Download ZIP](https://x-web-templates.pages.dev/downloads/swift-ai.zip)

![Swift AI screenshot](https://x-web-templates.pages.dev/assets/swift-ai.png)

One illustrated landing-page template reconstructed from the first forest direction in [Muddasir’s original post](https://x.com/hussain_mu20778/status/2097891688777932949?s=20). The other three backgrounds are intentionally excluded. Original native ChatGPT art replaces the reference illustration; typography uses licensed Nimbus Sans as an honest structural substitute. Attribution is not affiliation.

Open `dist/index.html` directly, or serve the folder with any static server. All HTML, CSS, JavaScript, art and fonts are local; no installation or runtime dependencies. Edit copy in index.html, styles in style.css, and local interactions in app.js. Replace assets/forest.png to change the artwork.

Navigation opens local example content. Try for free validates the email locally and opens a sample checklist; no account, email or signup is created. Get a quote prepares a downloadable text brief, not a real quote request. Login explains the unconnected account boundary and returns to the preview. Drafts remain on the current page until reload. Sample brand identities are illustrative, not customer proof.

The artwork is static, matching the still reference. Keyboard focus, native dialogs, mobile layouts, reduced-motion hover feedback, missing-art feedback and disabled-script reading are supported. With scripts disabled, navigation opens inline details and form submission is disabled. Generation prompt and source/QA receipts are in evidence/swift-ai in the private repository. Built-in image generation made one accepted image; billing was unavailable.
