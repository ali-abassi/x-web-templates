# telemetry-stack

[Live preview](https://x-web-templates.pages.dev/telemetry-stack/) · [Download ZIP](https://x-web-templates.pages.dev/downloads/telemetry-stack.zip)

![telemetry-stack screenshot](https://x-web-templates.pages.dev/assets/telemetry-stack.png)

Standalone motion template inspired by [Better Stack / Supahero](https://betterstack.com/). Discovered through [the original post](https://x.com/thedzianis/status/2097600028416381178?s=20).

Open dist/index.html or serve this folder with any static server. Edit HTML content, CSS design tokens and app.js behavior. All fonts and art are local; no build step or runtime dependency.

Motion: Dashboard scene transitions and timed carousel; moving logo row.
Interaction: Navigate monitoring scenes and pause autoplay.
Boundary: local demonstration only; no backend, account, message delivery or checkout. Reference credit is not affiliation or a claim to original assets.
