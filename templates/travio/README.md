# Travio

A standalone reconstruction of [Farhan ahmed Jibon’s travel-app concept](https://x.com/jibon33212/status/2098040111472800179?s=46). The alpine backdrop is original generated photography; the typography, phone, airplane, zipper and controls are editable HTML/CSS/SVG.

Serve `dist` with any static server. No build tools, packages, API keys or external fonts are needed. Direct `file://` launch has not been verified in the available browser.

**Get Started** opens a local preference preview. Enter a destination, choose a travel style, and preview the direction. Edit either field to revise; Escape or the close control returns to the splash. Choices remain in this tab until reload. There is no AI request, booking, account, tracking or storage. Without JavaScript the same link reveals the preference section, with preview clearly disabled.

Edit `dist/index.html` for copy, SVG artwork and form options, `dist/style.css` for layout and colors, and `dist/app.js` for the three local travel-style suggestions. Replace `dist/assets/mountains.png` to change both alpine views. Font licensing is included in `licenses/Nimbus-fonts.txt`.

Desktop preserves the presentation board; mobile turns the phone into a full-screen splash. Source evidence is one still, so no source animation is claimed or added. The original photograph, proprietary font identity and unpublished onboarding screens are not reproduced. Actual iOS, Safari and VoiceOver remain unverified.
