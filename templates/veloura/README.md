# Veloura

A monochrome botanical hero reconstructed from [Altamash’s reference](https://x.com/AltamashAyazz/status/2098071500934775112). Original generated flowers and a silver butterfly sit behind editable HTML copy. CSS folds the wings and gently moves the butterfly; this is a reconstruction of the observed motion, not the original renderer.

Open `dist/index.html` directly, or serve `dist/` with a static server. No package install, account, key or backend is required.

## Customize

- `dist/index.html`: headline, navigation, local details and project-note copy.
- `dist/style.css`: layout, type scale, image placement and wing/flight timing.
- `dist/app.js`: pause/reduced-motion/hidden-page handling, dialogs, local note preview and download.
- `dist/assets/flowers.png` and `butterfly.png`: original native image-generator artwork. The butterfly has an opaque black background and is composited with CSS screen blending; it is not an alpha cutout.
- `dist/assets/sans.otf`: Nimbus Sans, licensed under the included font notice.

Contact is a local note demonstration. It sends nothing, has no email/password field, and keeps the draft only until reload. Empty notes are rejected; preview, editing, cancellation and text download work locally. Failed download leaves the text available to copy. Replace the contact destination before using this as a business website.

Pause motion is below the hero. Reduced-motion preference disables animation; hidden pages pause. With JavaScript disabled, the artwork is still, anchor-linked details remain readable, and the note can be copied manually. Gallery/Templates and the template ZIP link use the public collection and need internet; local artwork, copy, dialogs and the note do not depend on a backend.
