# Wandor

[Live preview](https://x-web-templates.pages.dev/wandor/) · [Download ZIP](https://x-web-templates.pages.dev/downloads/wandor.zip)

![Wandor screenshot](https://x-web-templates.pages.dev/assets/wandor.png)

A landmark-filled journey with editable local itinerary downloads. A reference-led reconstruction of [the original design](https://x.com/oiharshit/status/2097666212767633581), with independently authored code and original artwork generated through native ChatGPT image generation. The source post contains still images; the animation is a new, restrained interpretation, not an observed source animation. Credit is not affiliation.

Open `dist/index.html`, or serve this folder with any static server. Edit the HTML content, CSS and `app.js`. Assets and fonts are local; no install, backend, API key or build step is needed. Font licenses are included. Keyboard controls, pause, reduced motion and script-free reading are supported.

Local demo boundary: trip notes become an editable example itinerary that can be downloaded as plain text. Dashboard controls change local example views. No AI call, booking, account, real-time update or travel verification occurs. Notes are kept only in the current page until reload; download a copy to retain them.

Artwork: landmark hero, floral border, airplane window, temple roof, world-landmark footer and Venice preview photograph. The repeated journey panel in the original two-column presentation appears once in this continuous page.

Generation prompts and provenance: [`evidence/olympus-wandor/image-generation.json`](https://github.com/ali-abassi/x-web-templates/blob/main/evidence/olympus-wandor/image-generation.json) in the source repository. Native-tool billing was not available. Desktop/mobile captures and the delivery receipt are retained with the same evidence folder.
